# POWERZONE ⚡ - High Performance Gym Landing Page

Landing page moderna y futurista para **POWERZONE**, diseñada con estética *cyber-athletic* (modo oscuro profundo `#070707`, acentos verde lima neón `#ccff00`, efectos glassmorphism, tipografía moderna y micro-interacciones).

## 🚀 Características Principales

- **Hero HUD Interactivo**: Sistema *Powerzone Performance System* con métricas en tiempo real, cálculo de calorías y onda ECG animada en Canvas.
- **¿Qué estás buscando?**: 4 tarjetas HUD interactivas con esquinas tecnológicas para objetivos específicos de entrenamiento.
- **Tu Programa Personalizado & Score**: Filtros por objetivo y frecuencia, tarjetas de días de entrenamiento y gráfica radial interactiva *Powerzone Score* con modal calculadora.
- **The Powerzone Method**: 4 pilares fundamentales de rendimiento y fuerza.
- **Instalaciones & Coaches**: Mapa visual del gimnasio con puntos pulsantes interactivos y carrusel de entrenadores destacados.
- **Transformaciones & Retos**: Comparador antes/después deslizante, cuadrícula de clases semanales con filtros y leaderboard del Powerzone Challenge.
- **App & Comunidad**: Mockup 3D de aplicación móvil y sección comunitaria.
- **Planes & FAQ**: Tabla de membresías (Basic, Premium, Pro Elite) y acordeón interactivo de dudas frecuentes.

## 🛠 Tecnologías Utilizadas

- **HTML5** semántico
- **Vanilla CSS3** (variables CSS, flexbox, CSS grid, glassmorphism, animaciones)
- **JavaScript (ES6+)** para interactividad, cálculo en tiempo real y animación Canvas
- **Google Fonts** (`Outfit`, `Plus Jakarta Sans`)
- **FontAwesome 6**
